用 Cookie 登录

      

        适合「已经在自己日常浏览器里登录了 Pixiv」的情况，把登录态直接搬过来，不用再登一次。
      

      
    
        
  1. 在你日常用的浏览器里打开 pixiv.net，确认右上角是你的头像
    2. 
        
  2. 按 F12 打开开发者工具，切到 网络 / Network 标签
    3. 
        
  3. 按 F5 刷新页面
    4. 
        
  4. 点列表里任意一条 pixiv.net 的请求
    5. 
        
  5. 右侧找 请求标头 / Request Headers，把 cookie: 后面那一整行复制下来
    6. 
      

      

        更省事的办法：应用 / Application → 存储 / Cookies →
        https://www.pixiv.net，找到 PHPSESSID 那一行，
        只复制它的值粘进来就行，程序会自动补成 PHPSESSID=值。
